# Character Decks

Every deck is 28 cards, 12 starting HP, and uses the five core symbols. See
[`../docs/03-design-principles.md`](../docs/03-design-principles.md) for the rules that govern
design, and [`../templates/character-deck-template.md`](../templates/character-deck-template.md)
for the required document structure.
