This game needs a web server to load its JavaScript modules. Keep the whole project folder together, including src and Styles.css.

For local play, open a terminal in the NewTest folder and run:

python -m http.server 8765 --bind 127.0.0.1

Keep that terminal running, then open the local game. If the server is already running, just use the link.

For the published game, use its GitHub Pages address instead of downloading only this HTML file.
